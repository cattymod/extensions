Create Scratch 3 style popup windows with titles, text, buttons, and embedded web pages.

Unsandboxed UI



How to use Modals

1. Press Download to download modals.js and open CattyMod Studio in a new tab.

2. In CattyMod Studio, click the Add Extension button in the bottom-left corner.

3. Click the CattyMod category.

4. Select Custom Extension.

5. Open the Files tab.

6. Enable Run without sandbox.

7. Upload the downloaded modals.js file and click Load.
