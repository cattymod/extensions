CattyMod Extension Gallery

The official place to find extensions made for CattyMod.

These extensions may not work in Scratch.
Projects using these extensions should be opened in CattyMod or another compatible editor.
Some extensions require unsandboxed mode.
All extensions here have been tested, but you do not have to use them. It's fine to just use the ones from TurboWarp already in the gallery.
How to load extensions from here

1. Hover over an extension and click Download.

2. Open CattyMod Studio.

3. Open Add Extension and choose Custom Extension.

4. Upload the downloaded extension file in the files tab.

5. Enable unsandboxed mode if the extension requires it.
